# Postbox interface

Postbox directly adapts the MIT-licensed [shadcn-admin](https://github.com/satnaing/shadcn-admin) inset layout, sidebar menu and team switcher, from commit e16c87f213a5ba5e45964e9b67c792105ec74d26. License attribution is in `THIRD_PARTY_NOTICES`. Inter is bundled locally in `web/public/fonts` under the SIL Open Font License, with no runtime font service dependency.

The desktop sidebar is 256px wide with 8px outer inset, 48px workspace/account buttons, 32px menu rows, 16px icons and 14px labels. General and Other groups use 8px padding and 32px group headings. The brand dropdown switches real brands and creates brands for administrators. The persisted collapsed inset rail has a 66px outer container and 32px icon buttons, with the main inset starting at 72px; the mobile Radix Dialog sheet is 288px, with focus trapping, Escape handling and an accessible close control. The header is 64px, with working route navigation, page search (Command/Ctrl K), three individually accessible System/Light/Dark controls, and the real creation menu.

The main inset has a 14px radius, 8px outer spacing and centered content up to 1280px with 24px vertical and 16px horizontal padding. Headings use 24px bold Inter. The palette uses white light-mode surfaces and neutral charcoal dark-mode surfaces, with neutral text, secondary surfaces, borders and inputs. Amber accents inspired by [Amber Minimal](https://www.shadcn.io/theme/amber-minimal) are reserved for primary actions, focus rings, subtle interaction and selected-state highlights, and charts. Chart series use amber, blue and teal tokens; status colors remain semantic. KPI cards retain all six real API metrics, their previous-period comparisons, subscriber snapshots and UTC hourly sending data. Unavailable metrics and comparisons stay explicit.

Existing page class contracts remain available: `page-heading`, `page-header`, `page-subtitle`, `page-tabs`, `toolbar`, `toolbar-search`, `table-card`, `table-toolbar`, `table-footer`, `row-title`, `row-subtitle`, `avatar`, `section-heading`, `empty-panel`. Table filters, campaign sending safeguards, CSRF authentication and administrator restrictions retain their existing behavior.

Shared Radix Checkbox and Select controls provide consistent focus, keyboard behavior, disabled states and label spacing. Inputs and select values use normal text weight while labels remain medium. Settings sections align left. Subscriber rows open their profiles directly with pointer and keyboard support; selection checkboxes do not activate the row. The sending control shows a Pause or Play icon and names its action explicitly. The canonical subscriber route is `/subscribers`; existing `/contacts` bookmarks redirect. Database tables and indexes already use subscriber names, so the package rename does not require a schema migration.
